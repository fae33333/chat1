إعدادات البحث في يوتيوب غير مفعّل

البحث في المنشورات وقائمة الموسيقى داخل الغرف يعمل بدون مفتاح عبر بديل مجاني تلقائياً.
لكن للحصول على نتائج أدق وحصة أعلى، يُفضّل إضافة YOUTUBE_API_KEY من Google Cloud Console. يمكنك إضافته هنا أو عبر ملف .env — يُحفظ ويُفعّل فوراً بدون إعادة تشغيل.

🔑 مفتاح YouTube Data API v3
📖 كيف تحصل على المفتاح في دقيقتين؟
  1. ادخل إلى Google Cloud Console وسجّل دخولك.
  2. أنشئ مشروعاً جديداً أو اختر مشروعاً موجوداً.
  3. من القائمة: APIs & Services → Library ابحث عن YouTube Data API v3 واضغط Enable.
  4. من APIs & Services → Credentials → Create Credentials → API key انسخ المفتاح.
  5. الصقه هنا واضغط حفظ — أو ضعه في ملف .env كـ YOUTUBE_API_KEY=AIza... وأعد تشغيل الخادم.

الحصة المجانية: 10,000 وحدة يومياً (≈ 100 بحث). عند انتهائها يتحول البحث تلقائياً للبديل المجاني.
